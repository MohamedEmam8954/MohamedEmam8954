## `03 // ARCHITECTURE`

My approach to application structure is centered around **separation of responsibilities**.

```text
┌─────────────────────────────────────────────┐
│                    PRESENTATION             │
│                                             │
│          Screens • Widgets • UI             │
└──────────────────────┬──────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────┐
│                STATE MANAGEMENT             │
│                                             │
│                 BLoC / Cubit                │
└──────────────────────┬──────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────┐
│                 APPLICATION                 │
│                                             │
│             Business / Domain Logic         │
└──────────────────────┬──────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────┐
│                    DATA                     │
│                                             │
│      APIs • Repositories • Models           │
│      Storage • Services                     │
└─────────────────────────────────────────────┘
```

### Principles I Care About

```text
Separation of Concerns
        ↓
Single Responsibility
        ↓
Reusable Components
        ↓
Predictable State
        ↓
Testable Logic
        ↓
Maintainable Code
```
